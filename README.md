BiteDesk - Restaurant POS System

A modern Restaurant Point of Sale web application.

## 🚀 Features
- Interactive food menu
- Food category filtering
- Search functionality
- Shopping cart
- Discount calculation
- Receipt printing

## 🛠️ Technologies Used
- HTML
- CSS
- Tailwindcss
- JavaScript
- ReactJs
